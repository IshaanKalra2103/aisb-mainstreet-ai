What it is

An owner pastes their website, or types one line like "2-van HVAC company in Frederick, MD". An AI agent reads the business, picks the jobs AI could take off their plate, compares tools from a catalog a person has checked, and only after the owner says yes, signs up and sets one up. Same agent on the web and over iMessage.

1Reads your business

Type, size, town, the software you already use, what slows you down.

2Finds the jobs

3 to 5 jobs from a fixed list of 9, ranked by hours saved a week.

3Compares tools

2 to 3 checked tools per job: price, setup, works-with, trust score.

4Sets it up

Only on your yes, free plan, in a cloud browser. Or a local helper.

Why it's built the way it is

Start from a website, not a search box
Owners don't know the AI words. They know their business, so we start there. No site? One sentence works.
A fixed list of 9 jobs
Real pains (27% of home-services calls go unanswered, Invoca). The agent can't invent a category.
Trust score, not star ratings
Six checks out of 100, each linked to evidence: who's behind it, age, data handling, public prices, independent reviews, still shipping. Verified = 75+ and a person's sign-off. Unknown builders stay hidden.
The agent does the setup
Setup is the drop-off, so we do it. Never enters a card; hands CAPTCHAs and phone checks to the owner.
"Yes" is enforced in code
A website can tell an agent to ignore its rules, so the owner's decision lives where the agent can only read it. No yes for that exact tool, no sign-up.
Phone first, people too
Owners live on their phones, so iMessage. Want a person? Maryland SBDC, SCORE, SBA Baltimore.

Real, not a wireframe

Pipeline: discover, read, extract, vet, human review. Reruns weekly so the catalog grows. 24 unknown-builder tools kept out; every business type has 2+ approved tools per job.

Stack: Next.js on Vercel, FastAPI, each agent turn in a locked-down container (Claude Code, six tools, no open web, spend caps), TinyFish web + cloud browser, AgentMail inboxes, iMessage relay.

Why can't OpenAI or Anthropic do this overnight?

They could build the chat. The chat isn't the hard part:

  • a catalog a person checks against evidence, every week
  • Maryland partners owners already trust (SBDC, SCORE, SBA)
  • actually setting the tool up, safely, for the owner
  • being accountable to owners in our own state
